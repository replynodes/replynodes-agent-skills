# Public provenance

This package is authored documentation for the public gateway route surface
under `https://api.replynodes.com/v1/fomo`. Route names, parameters, and
response envelope behavior were checked against the repository’s public API
documentation and gateway route definitions at review time.

The package intentionally contains no FOMO service implementation, raw live
payloads, wallet addresses, credentials, API keys, user credentials, or
secrets. The source repository is
`replynodes/replynodes-agent-skills`; the package path is
`skills/fomo-app-data-api`.
