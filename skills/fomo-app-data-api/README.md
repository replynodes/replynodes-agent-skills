# Fomo App Crypto Trading API

Published skill slug: `fomo-app-data-api`.

Read-only FOMO App Data API skill for agent research and market data across
Solana, meme coins trading, crypto, social trading, and on-chain activity. The
API base is `https://api.replynodes.com/v1/fomo`.

Install this directory as a skill. The package contains instructions only: it
has no service code, dependencies, credentials, wallet data, external-account
access, or investing advice.

The supported routes and read-only handling are in [`SKILL.md`](SKILL.md). The
package deliberately excludes wallet signing, transactions, trade execution,
and all mutations. ClawHub publishes this folder and generates its own skill
card; the local [`skill-card.md`](skill-card.md) is retained for review only
and is excluded from the published package.
