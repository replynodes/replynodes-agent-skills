# App Store Public Reads

- **Slug:** `appstore-api`
- **Version:** `1.0.10`
- **License:** `Apache-2.0`
- **Mode:** `readonly`
- **Summary:** Read-only, normalized public-data reads of App Store applications through the ReplyNodes App Store public-read service: app lookup by track id or bundle id, bounded term search, and related-app listings. Bearer workspace-key authentication or x402 v2 payment negotiation at the gateway, transparent bounded pages, normalized errors, and an explicit unsupported-capability matrix. Public reads only: no purchase, review, account, or other mutation exists, and no platform login material is involved.

This card describes only the documented GET capabilities in `manifest.json`.
It does not claim registry publication, live availability, payment settlement,
platform endorsement, or write/account access.
